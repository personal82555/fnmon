     1|# 💻 fnmon — fnOS 全功能系统监控面板
     2|
     3|> 一款专为飞牛 fnOS 打造的**实时系统监控面板**，一个 Docker 命令即可拥有媲美专业 NAS 监控的 Web 界面！
     4|
     5|---
     6|
     7|## 🎯 简介
     8|
     9|**fnmon**是一个轻量级的 Web 监控工具，以 Docker 容器方式运行在飞牛系统上。无需安装额外驱动、无需修改系统文件，一条命令跑起来就能用。
    10|
    11|它提供了传统 NAS 系统（如群晖 DSM、威联通 QTS）才有的可视化监控体验，但专为飞牛 OS 深度定制。
    12|
    13|---
    14|
    15|## ✨ 功能亮点
    16|
    17|### ⚡ CPU 监控
    18|- 实时频率显示（每个核心独立展示）
    19|- Governor / EPP 运行模式
    20|- 核心温度（支持 SATA/HDD/SDD/NVMe）
    21|- Turbo Boost / 超频检测
    22|- 60 秒频率历史曲线图
    23|- **CPU 评测跑分数据**（PassMark、Cinebench、Geekbench）
    24|- **同级 CPU 横向对比柱状图**（N100/J4125/i5-8400T/i3-12100...）
    25|
    26|### 🧠 内存监控
    27|- 总容量 / 已用 / 可用 / 缓存
    28|- SWAP 使用情况
    29|- 内存历史趋势图
    30|
    31|### 🌐 网络监控
    32|- 实时网速（上传/下载）
    33|- 总流量统计
    34|- **Docker 容器流量排行**（哪个容器最占带宽一目了然）
    35|- 按日/月/年统计
    36|
    37|### 💾 磁盘监控
    38|- 所有磁盘设备列表
    39|- **物理硬盘健康状态**（SMART 信息）
    40|  - 🌡 硬盘温度
    41|  - ❤️ NVMe 寿命百分比
    42|  - ✅ SATA 健康状态（PASSED/FAILED）
    43|  - 🔄 通电时间
    44|  - 💾 总写入量
    45|
    46|### 📱 应用用量排行
    47|- 综合 CPU + 内存 + 网络 三维度评分
    48|- 按 **日/周/月/年/总计** 排行
    49|- 一键切换时间维度
    50|
    51|### 🔝 进程 CPU 占用排行（TOP 20）
    52|- 实时刷新，按 CPU 占用排序
    53|- 显示 PID、用户、启动时间
    54|- CPU% 颜色标识（红 > 50% / 橙 > 20% / 黄 > 5%）
    55|

    89|## 🚀 快速安装
    90|
    91|### 方式一：Docker 一键运行（推荐 👍）
    92|
    93|```bash
    94|docker run -d \
    95|  --name fnmon \
    96|  -p 5000:5000 \
    97|  --privileged \
    98|  -v /proc:/proc:ro \
    99|  -v /sys:/sys:ro \
   100|  jinghui1984/fnmon:latest
   101|```
   102|
   103|启动后浏览器访问：**http://飞牛IP:5000**
   104|
   105|### 方式二：Docker Compose
   106|
   107|创建 `docker-compose.yml`：
   108|
   109|```yaml
   110|version: '3'
   111|services:
   112|  fnmon:
   113|    image: jinghui1984/fnmon:latest
   114|    container_name: fnmon
   115|    restart: always
   116|    ports:
   117|      - "5000:5000"
   118|    privileged: true
   119|    volumes:
   120|      - /proc:/proc:ro
   121|      - /sys:/sys:ro
   122|```
   123|
   124|运行：
   125|```bash
   126|docker compose up -d
   127|```
   128|
   129|### 方式三：SSH 离线安装
   130|
   131|下载 fpk + 脚本：
   132|
   133|| 文件 | 说明 |
   134||------|------|
   135|| `fnmon-v1.0.15.fpk` | fnOS 应用包（44KB） |
   136|| `install.sh` | 一键安装脚本 |
   137|
   138|```bash
   139|sudo bash install.sh
   140|```
